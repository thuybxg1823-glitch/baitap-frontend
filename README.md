Bài tập Frontend cơ bản - Buổi 01
1. Giới thiệu
Website giới thiệu các khóa học lập trình dành cho người mới bắt đầu.
2. Mục tiêu
- Làm quen với cấu trúc HTML.
- Sử dụng các thẻ Heading, Paragraph, Link và List.
- Xây dựng Landing Page cơ bản.
3. Cấu trúc website
- Header: Logo và menu điều hướng.
- Hero Section: Tiêu đề, thông điệp và CTA.
- Nội dung: Giới thiệu, khóa học và lợi ích.
- Footer: Thông tin liên hệ.
4. Công nghệ sử dụng
- HTML5
